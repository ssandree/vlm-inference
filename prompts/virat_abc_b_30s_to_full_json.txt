You are given event lists extracted independently from consecutive 30-second windows of the same surveillance video.

Your task is to produce the final full-video event list.

IMPORTANT:
The input events have already been extracted.
Do NOT summarize them.
Do NOT reorganize them into larger high-level activities.
Do NOT merge events merely because they are temporally close.

Your primary task is CROSS-WINDOW EVENT RECONCILIATION.

RULES:

1. Preserve every valid input event by default.

2. Merge events across adjacent 30-second windows ONLY when there is sufficient evidence that they describe the continuation of the same subject performing the same ongoing action or action sequence.

3. A 30-second window boundary is NOT an event boundary.

For example:

Window 0–30:
[27–30] A person approaches a vehicle.

Window 30–60:
[30–36] The person reaches the vehicle and enters it.

If the descriptions clearly support continuity, these may become:

[27–36] A person approaches the vehicle and enters it.

4. Do NOT merge independent events.

Events involving different subjects or unrelated actions must remain separate, even if they occur at the same time or close together.

5. Preserve overlapping events.

Two independent events may have overlapping time ranges.

6. Preserve short and subtle events.

Do not remove an event because it is brief, distant, small, or less salient.

7. Remove only clear duplicate representations of the same event.

Do not remove events merely because their descriptions are similar.

8. Do not invent continuity across windows.

If it is uncertain whether two events involve the same subject or continuing action, keep them separate.

9. Do not invent new actions, identities, intentions, causes, interactions, or temporal details.

10. Preserve the temporal precision supported by the input events.

INPUT WINDOW EVENTS:

{WINDOW_EVENT_JSONS}

Return valid JSON only:

{
  "events": [
    {
      "start": <seconds>,
      "end": <seconds>,
      "description": "<specific observable event>"
    }
  ]
}
