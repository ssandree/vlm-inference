LLM semantic judge 평가 결과

대상: 5개 모델 × 2개 조건 × annotation available 9개 영상 = 90개 설명. 원본 GT는 영상 9개에 총 36개 이벤트. 이 세션의 GPT-6 LLM이 설명 전체를 읽고 의미 판정했으며 keyword/regex 채점은 사용하지 않았다. 구조 파싱과 판정 라벨 집계만 Python으로 수행했다.

평가 단위와 해석
주요 action recall은 영상별 고유 행동 유형 17개 기준 의미 충족률이다. 동일 행동의 여러 트랙·구간과 개인/그룹 중복을 합친다. 방향 recall은 고유 (영상, 행동, GT 방향) 7개 기준이다. 원본 GT 36개별 판정은 별도로 모두 제공하되 한 행동 언급이 여러 GT ID에 투영될 수 있으므로 개별 이벤트/주체를 식별한 instance recall이 아니다. 이 차이를 숨기지 않기 위해 아래 원본 GT 기준 보조표를 함께 제공한다.
Action precision은 추출한 고유 핵심 예측 행동 중 GT가 지지하는 비율이다. 환각률 H는 요청에 따른 closed-world GT 비지원 이벤트율이다. 이 GT는 차량 이동·배경 행동 등이 누락될 수 있어 H를 실제 영상의 확정 환각률로 해석하면 안 된다. 실제 영상 검증 환각률은 산출하지 않았다. 행동-방향 결합 충족 여부도 GT 상세표의 joint_label로 제공한다.
정적인 자세·배경·OCR·색상·인원수·시각은 채점 범위 밖이다. 차량 이동·주차·보행·대화·물체 조작 등 확신적으로 서술된 핵심 동작은 예측 행동에 포함한다. 따라서 GT에 없는 보행이나 자동차 이동 역시 GT 비지원 항목이 될 수 있다.

Uncertain 및 점수 규칙
matched/correct/supported=1, missed/missing/contradictory=0, uncertain=0.5. Uncertain 예측은 precision에 0.5, 비지원율에 0.5 반영한다. 0점·1점 민감도 범위는 신뢰구간이 아니다. 방향 누락은 방향 recall에서 0점이며 GT 방향이 null이면 분모에서 제외한다.
종합점수 = 100 × [0.50 × action recall + 0.20 × action precision + 0.20 × direction recall + 0.10 × (1 − H)]. 본 정의에서는 P=1−H이므로 실효 가중치는 행동 50%, GT 지지 precision 30%, 방향 20%다. 9개 영상의 분자/분모를 합산한다. 모델 순위는 두 조건 점수의 동일 가중 평균이다.

원본 36개를 각각 집계하면 30b가 1위, 중복을 제거한 의미 유형에서는 30b-fp8가 1위다. 30b의 한 right-to-left 보행 구절이 여러 GT 트랙·그룹·시간 구간으로 투영되어 방향 점수가 커지기 때문이다. 평가 단위에 따라 1·2위가 바뀌므로 단일 우승 모델로 단정하지 않는다.

해석 (5줄)
1. 30b 계열은 full_frame에서 차량 하차와 건물 출입을 명시하여 8b 계열보다 높은 행동 커버리지를 보였다.
2. motion_roi는 여러 모델에서 차량 하차·탑승 및 출입문 통과를 더 구체적으로 기술했다. 다만 30b는 full_frame에 있던 일부 건물 출입과 방향 단서를 ROI에서 잃었다.
3. 010114 영상의 트렁크 열기·닫기, 차량 탑승, 달리기는 모든 모델·조건이 놓쳤다. 보행/자전거/자동차 이동 설명으로 이를 대체할 수 없다.
4. 방향은 전반적으로 누락되며 계단 상하 이동·화면 내 위치·차량 방향을 사람의 이동 방향으로 인정하지 않았다. 특히 30b-fp8 full_frame의 차량 right-to-left는 보행 방향 점수가 아니다.
5. 길고 다양한 설명은 GT에 없는 행동도 추가하므로 GT precision이 낮아질 수 있다. 상위 순위의 uncertain 범위가 겹치며, GT 누락·판정 단위·단일 judge 때문에 점수 차이를 실제 영상 정확도의 확정적 우열로 해석하지 않는다.

재현성
온도와 seed는 현재 세션에서 설정·확인할 수 없어 null로 기록했다. temperature=0 API 실행을 했다고 주장하지 않는다. 고정 루브릭으로 이 세션 LLM이 직접 판정했으며 블라인드 평가나 독립 judge 검토는 수행하지 않았다. 저장된 판단에 대한 수치 재계산은 결정적이다. 새 LLM 판정의 완전 동일 재현을 보장하지 않는다.
실행: python prepare_inputs.py → python author_judgments.py → python evaluate.py
author_judgments.py는 이번 LLM이 내린 판정을 직렬화하는 스크립트이며 새 모델 추론을 수행하는 자동 judge가 아니다. 판정 변경 없이 재계산할 때는 python evaluate.py만 실행한다. 새 판정은 judge_prompt.txt와 inputs.json을 LLM에 제공하고 동일 스키마의 judge_results.json으로 저장한 뒤 evaluate.py로 집계해야 한다.
입력 파일 SHA-256은 input_manifest.json, 실행 및 판정 파일 정보는 run_metadata.json에 저장했다. per_video_details.json/tsv, gt_event_details.tsv, predicted_event_details.tsv, uncertain_cases.json에서 원문·판정·근거를 검토할 수 있다.

Judge prompt 전문
You are an LLM semantic judge comparing one video caption with caption_events.json.
Read the entire caption and all GT events. Do NOT score by keyword presence, regex,
word overlap, embedding thresholds, or synonym dictionaries. Metadata parsing and
arithmetic may use code; all meaning judgments must be made by the LLM.

TASK AND SCOPE
1. Extract distinct, confidently asserted, core dynamic action propositions from
   the caption. Use one prediction per semantic action type per caption; coalesce
   repetitions, actor counts and paraphrases. Include walking, cycling, driving,
   parking, carrying, talking, gestures, facility transitions, vehicle transitions,
   and manipulation of objects when asserted. Driving/turning/passing/driving away
   form one driving proposition; parking is separate. Pausing/stopping within
   movement, entry/exit from the camera frame, and approaching are not extra action
   types. Static sitting/standing, scenery, weather, shadows, tree movement, birds,
   color, OCR, exact counts and timestamps are outside this core-event evaluation.
   Deliberate holding/carrying an object can be carrying; incidental 'holding head'
   is NOT carrying. Static presence at a doorway is not proof of a transition.
2. For every distinct GT action type, decide matched, missed, or uncertain and
   give an exact supporting caption excerpt when matched/uncertain plus a short
   Korean explanation. Synonyms, paraphrases and sentence order are irrelevant.
   Describe what is semantically asserted rather than what probably happened.
   Going towards a door is not entering. Exiting the image is not exiting a
   facility. Going down stairs does not entail leaving a building. Opening an
   ordinary car door is not opening the trunk. Walking is not running. Cycling
   is not walking. Conversation is not necessarily gesturing. An explicit
   'enters/exits through glass doors' entails the corresponding facility action.
   Ambiguous 'passing through doorways' may be uncertain as to entering/exiting.
   Uncertainty must concern the meaning of this specific description, not be a
   substitute for missed evidence. Do not infer an action merely to complete GT.
3. This is CAPTION SEMANTIC COVERAGE, not track-localized detection. Exact counts,
   timestamps and track identity are not scored. Because GT contains multiple
   tracks, repeated segments, and both group and constituent events, primary
   recall counts unique (video, subject category, action) units. All 36 original
   GT IDs must also be retained and reported as semantic-coverage projections;
   a projected match is NOT proof that each distinct actor/event was described.
   Report raw-event coverage separately, never silently call it instance recall.
4. Direction is evaluated only for GT actions with non-null direction. Count
   unique (video, action, direction) units in the primary metric. Judge correct,
   missing, contradictory, or uncertain using directions attached to the SAME
   action/actor clause. 'On the left' is location, not leftward motion; ascending
   stairs is not bottom-to-top screen motion; vehicle direction cannot support
   pedestrian direction. Heading right entails left-to-right motion, but cannot
   establish a diagonal. Do not collapse diagonal and horizontal labels. For
   multiple actors, do not transfer one person's direction to a carrying person
   or infer contradiction if unspecified alternative actors remain possible.
   If action is missed, direction is missing. For ambiguous action evidence,
   any direction credit must also be uncertain at most. A full GT semantic match
   additionally requires correct direction whenever GT specifies direction.
5. For each extracted predicted action, label:
   supported: semantically grounded by a GT action (action precision ignores
              direction, which is separately scored);
   hallucinated_gt: confidently asserted core action not supported by this GT;
   uncertain: its semantic interpretation/support is ambiguous.
   IMPORTANT: hallucinated_gt is the USER-REQUESTED closed-world GT-unsupported
   label, NOT a visually verified false event. The GT policy explicitly says
   GT is non-exhaustive, absence does not mean false, vehicle/background activity
   may be missing, and unsupported claims require video verification. Record
   factual_status=uncertain_unverified for every hallucinated_gt prediction.
   Do not invent a factual hallucination rate from these annotations alone.
   A GT-only prediction can be supported even if count/time/color is wrong,
   because those slots are outside scope. Action-direction errors are reported
   separately and are not counted twice as hallucinated action types.
6. Include exact evidence excerpts for EVERY extracted predicted action, including
   unsupported ones. Provide matched/missed/uncertain GT lists, unsupported
   predictions, and rationales. Model and condition may be visible: do not use
   their identities as evidence. No claim of blind or independent evaluation.

OUTPUT CONTRACT
Each record has record_id, action_judgments (action, label, evidence, reason_ko),
direction_judgments (action, gt_direction, label, evidence, reason_ko),
predicted_events (action, label, evidence, reason_ko, factual_status), and optional
notes_ko. Allowed labels are those above. Excerpts must be verbatim substrings.

SCORING (FIXED BEFORE AGGREGATION)
Let uncertain weight w=0.5. Matched/correct/supported earns 1, missed/missing/
contradictory earns 0. Report sensitivity at w=0 and w=1, not confidence intervals.
Action recall R = (matched GT action units + w*uncertain units)/GT action units.
Action precision P = (supported predicted action units + w*uncertain predictions)
                     /all predicted action units.
Direction recall D = (correct direction units + w*uncertain direction units)
                     /GT directional units (missing counts as zero).
GT-unsupported rate H = (hallucinated_gt + (1-w)*uncertain predictions)
                        /all predicted action units.
Composite = 100*(0.50*R + 0.20*P + 0.20*D + 0.10*(1-H)).
Since P=1-H here, the composite effectively weights action recall 50%,
GT-grounded precision 30%, and direction recall 20%; do not claim P and H are
independent evidence. Pool numerators/denominators across the nine videos for
model x condition. Rank models by equal mean of the two condition scores.
Also provide original-event projected action/direction/joint coverage and
per-video details. As a disclosed sensitivity analysis, also compute the same
composite using original-event projected action/direction coverage and report
its model ranking; do not interpret repeated coverage as distinct actor matches.
Undefined per-video direction/precision stays null; compute
composites only for pooled sets with defined denominators.
